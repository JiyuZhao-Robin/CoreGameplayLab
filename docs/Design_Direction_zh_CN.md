## 1. 产品判断与核心定位

当前项目不缺系统大类。

现有版本已经具备采矿、分选、冶炼、制造、科研、造船、远征、战斗、巨构和第一次星际远征的完整规则骨架；地点库存、实体运输、舰船生命周期和持续模拟也已经连接。当前内容已经达到 6 个区域、60 种资源、91 个活动/配方、19 类设施、16 项科技、10 种船体和 4 个文明级工程，不再是需要先补齐系统门类的小原型。

下一阶段真正需要扩张的是五种关系：

> **生产路线、工业规模、地点差异、物流成本、技术代际。**

目前中后期的主要问题是“换一种更高级的材料、提高一次门槛、打一个更强的敌人”，而不是让玩家面对新的工业问题。后续内容必须优先改变玩家的决策方式，而不只是增加更高数值。

项目的目标组合是：

> **Factorio 的生产逻辑  
> ＋ Victoria 3 的规模与建设  
> ＋《戴森球计划》的跨区域工业化  
> ＋ Stellaris 的战略地图与舰队组织  
> ＋ Endless Space 2 的视觉呈现和地点辨识度。**

最终产品定位：

> 玩家在 1 平方米方格构成的行星画布上规划宏观设施、固定矿体、电网和运输走廊，并把这些真实空间网络扩展为拥有实体舰船、地点库存、工业资本、建设能力和跨行星物流的太空工业文明。

换一种表达：

> Factorio 负责说明“东西怎样生产出来”；  
> Victoria 3 负责说明“生产规模为什么不能无限扩张”；  
> 《戴森球计划》负责说明“工业为什么必须走向远方”；  
> Stellaris 与 Endless Space 2 负责让玩家看见自己建立的文明。

这四层必须互相咬合，而不是成为彼此孤立的功能列表。

## 2. 核心设计支柱

### 2.1 方格空间中的宏观生产网络

直接采用 Factorio / Gridworks / DSPONLINE 的固定资源、实体占地、端口连接、线路吞吐、满仓反压、蓝图和自动化逻辑。行星可用面积由 1 平方米方格组成，但玩家放置的是采掘场、工业区、仓储区、电站和运输走廊等宏观 Footprint，不进入设施内部逐台操作机器。

### 2.2 有限建设能力，而不是即时升级

工业规模受到建设能力、资本品、地点容量、能源、散热和物流约束。扩建某一产业意味着暂缓另一产业、舰队、物流或巨构工程。

### 2.3 地点库存与真实运输是经济真相

资源属于具体地点。跨地点供应必须形成在途货物并占用路线、枢纽、装卸、推进剂、维护和能源。任何汇总“可达率”只能用于解释，不能取代真实物流。

### 2.4 技术改变组织方式

科技不仅解除门槛，还应开放新的生产方式、物流方式、自动化层级和工业体系，让老产业在新技术下重新组织。

### 2.5 实体舰船连接工业与前沿

舰船、标准模块、特殊装备和补给都应是工业产出与实际资产。舰队行动持续消耗弹药、推进剂、维修物资和服务能力，并把战斗掉落、远征产品、情报与特殊资产带回工业系统。舰船不参与矿物、气体或残骸点的实际采集。

### 2.6 规模扩大后操作应更抽象

前期允许玩家直接启动生产、配置路线；中期使用模板和目标产率；后期通过条件自动化、警报和例外管理文明。规模增长不能等价于重复点击增长。

### 2.7 表现层必须解释系统

星系地图、地点场景、舰队表现和巨构阶段不只是装饰。它们必须让玩家看见运输、拥堵、采掘、建设、战损、工业规模和文明成长。

## 4. 目标核心循环

工业深化后的主循环应形成以下关系：

```text
勘测地点与资源
        ↓
部署采矿舰 / 建立采掘网络
        ↓
远端粗加工 / 中心精炼之间做选择
        ↓
运输原料、材料、组件和工业设备
        ↓
制造资本品、标准舰船模块与补给
        ↓
竞争有限建设能力，扩建工业、电网、物流、船坞或巨构
        ↓
研究并采用新生产方式、运输方式和工业体系
        ↓
建造与组织舰队，突破新区域
        ↓
新地点、新危险与新资源迫使工业重新布局
        ↺
```

工业必须能够生产工业本身；技术必须能改造旧工业；地点必须因物理条件和运输位置而具有不同价值。

## 5. 重点深化方向一：资本品经济

### 5.1 设计目标

增加专门用于扩大生产能力的 `Capital Goods`，让玩家不只是生产资源和最终产品，还要生产工厂、物流、电网、船坞和巨构所需要的生产资料。

目标循环：

```text
采矿
→ 冶炼
→ 制造机床和工业设备
→ 占用建设能力扩建工厂
→ 获得更高产能和新工艺
→ 生产更先进的工业设备
```

### 5.2 首批资本品候选

| 资本品 | 主要用途 |
| --- | --- |
| 工业机床 | 冶炼厂、加工厂和装配厂扩建 |
| 自动化核心 | 后台工业、无人采掘、自动物流 |
| 热交换组件 | 高等级工业、聚变设施、外太阳系基地 |
| 电力总线组件 | 电厂、船坞和高能工业 |
| 重型结构段 | 大型设施、星港、巨构和大型船体 |
| 精密执行器 | 舰船模块、采矿设备和装配设备 |
| 船坞机械 | 船厂等级和大型船体生产线 |
| 物流装卸设备 | 物流枢纽、质量投射器和货运站 |

首轮内容规模以 8–12 种资本品为目标。最终数量由依赖关系决定，不能为了达到数量强行拆分中间物。

### 5.3 建设队列统一原则

以下行为必须进入真实建设队列，不再即时完成：

- 设施等级扩建。
- 仓储扩容。
- 电网升级。
- 散热和结构容量扩建。
- 船坞和装配线扩建。
- 物流枢纽与路线基础设施升级。
- 固定采掘网络建设与升级。
- 文明级工程。

每项工程至少竞争：

- 本地建设能力。
- 工程设备与资本品。
- 地点库存和物流运力。
- 建设时间。
- 发起设施或工程能力。

核心选择应当是：

> 有限建设能力现在用于钢铁、物流、能源、船厂、前沿基地，还是文明级工程？

### 5.4 资本品的设计约束

- 每种资本品必须被多个持续扩张系统消费，避免只为一个配方存在。
- 资本品不能全部由同一个万能设施生产。
- 低阶资本品应支持产业自举，高阶资本品应体现技术代际。
- 资本品短缺必须能通过瓶颈诊断追溯到原料、设施、能源或物流根因。
- 扩建不能因新体系导致主线软锁；至少保留一条低效但可靠的基础恢复路径。

## 6. 重点深化方向二：生产方式矩阵

### 6.1 从“更多配方”转向“有取舍的方法”

当前底层已经支持生产方式、设施模块和通用插件，但内容中的替代路线太少。下一阶段不以继续增加大量线性配方为目标，而要让四条重点产业链分别拥有 2–3 种明确取舍的生产方式。

生产方式至少应显著改变下列三项：

- 原料利用率。
- 生产速度。
- 能源需求。
- 散热压力。
- 废料或副产物。
- 维护需求。
- 货运体积。
- 所需设施、模块和资本品。
- 产品纯度或适用范围。

如果一种新方法只提供无条件的数值提升，它更适合作为升级，不应伪装成生产方式。

### 6.2 混合原矿处理示例

#### 远端粗分选

```text
混合原矿
→ 铁精矿 + 铜精矿 + 大量废料
```

- 设备便宜。
- 能耗低。
- 材料利用率较差。
- 显著减少运输体积。
- 适合小行星带和前沿基地。

#### 中心精密分选

```text
混合原矿
→ 更多铁矿 + 更多铜矿 + 稀有副产物
```

- 材料效率高。
- 需要精密设备和高等级能源。
- 需要把大体积原矿长距离运回成熟中心。
- 适合地球轨道或专业精密工业中心。

#### 高能等离子分离

```text
混合原矿
→ 高纯度金属原料
```

- 速度快。
- 能耗和散热要求极高。
- 维护成本高。
- 适合后期能源充足的工业枢纽。

### 6.3 产业链层级原则

主产业链通常维持 3–5 层：

```text
原始资源
→ 初级处理
→ 工业材料
→ 功能组件
→ 最终装备 / 设施
```

每增加一种中间物，至少满足一项：

1. 改变加工地点选择。
2. 改变运输成本。
3. 产生不同生产方式。
4. 被两个以上系统持续消费。
5. 成为自动化或技术跃迁的关键节点。

否则应与前后工序合并，不为了真实感制造没有决策价值的长链。

### 6.4 首批重点产业链

工业深化版本优先覆盖：

1. 钢铁与大型结构。
2. 电子与自动化。
3. 能源与散热。
4. 舰船、维修与物流设备。

首轮目标为 12–18 种生产方式，不要求平均分配，但每条重点产业链至少形成一个有效的地点、能源或运输选择。

## 7. 重点深化方向三：工业规模、地点容量与专精

### 7.1 地点核心容量

使用 1 平方米方格表达地表、资源、设施占地和连接路径；同时保留 4–5 类地点级容量，约束整个行星工业网络：

| 地点容量 | 代表含义 |
| --- | --- |
| 结构容量 | 可承载多少设施、船坞、仓储和巨构结构 |
| 散热能力 | 能支持多少高能耗工业 |
| 电力总线 | 本地可稳定分配的功率 |
| 转运吞吐 | 货物装卸、对接和内部搬运能力 |
| 特殊防护 | 辐射、低温、重力或深空环境适应 |

设施升级在提高产量的同时，必须持续占用这些容量。容量不足时应形成可解释的硬限制或效率下降，不能成为隐蔽的随机惩罚。

### 7.2 工业规模阶段

设施 1–30 级不能只是连续增加同一个百分比。建议按阶段产生质变：

| 等级 | 规模阶段 | 应开放的变化 |
| --- | --- | --- |
| 1–4 | 工坊 | 基础工艺、少量模块能力、人工操作为主 |
| 5–9 | 工厂 | 新生产方式、更稳定吞吐、初级模板 |
| 10–19 | 工业综合体 | 更多模块槽位、规模效应、专精能力和自动控制 |
| 20+ | 自动化工业区 | 后台工业、高级生产方式、远程管理和更高维护压力 |

跨越阶段时可以开放：

- 新生产方式。
- 新设施模块槽位。
- 更高自动化等级。
- 新的规模效应。
- 新维护或资本品需求。
- 更高能源、散热和物流压力。

### 7.3 地点工业专精

地点可选择工业专精，首轮目标 4 类，长期候选包括：

- 大宗冶炼中心。
- 精密制造中心。
- 燃料与低温工业中心。
- 舰船制造中心。
- 物流转运枢纽。
- 科研与特殊材料中心。

专精必须：

- 需要基础设施改造和建设时间。
- 消耗对应资本品。
- 有清晰收益和机会成本。
- 可以改换，但不能免费瞬时切换。
- 改变适用生产方式、容量利用或物流结构，而不只是增加通用产量。

### 7.4 地点归属原则

产业设施以具体地点归属为主。文明级能力提供科技、政策、全局上限和跨地点协调，不把真实地点设施重新抽象成无限共享的全局等级。

## 8. 重点深化方向四：货运属性与运输模式

### 8.1 保留真实运输底层

现有 `Supply`、`Demand`、保留量、目标库存、优先级、来源锁定、在途货物、多跳路径、路线容量、燃料和维护成本继续作为物流真相。

可以增加“物流可达率”“预计补足时间”等 UI 汇总指标，但不能使用类似抽象市场准入率的数字替代实体运输。

### 8.2 货运类型

物品不必计算真实公斤数，但应归入少量可理解的货运类型：

- 大宗散货。
- 标准工业货物。
- 精密组件。
- 低温货物。
- 危险货物。
- 超大型结构件。

货运属性至少影响路线容量占用和可用运输方式；特殊货物还可以要求冷却、防护、装卸设备或专门维护。

### 8.3 运输方式

首轮实现 3–5 类运输方式，长期候选如下：

| 运输方式 | 最适合 | 主要代价 |
| --- | --- | --- |
| 通用货运舰 | 标准工业货物 | 容量适中，通用但不专精 |
| 大宗拖船 | 矿石、金属和粗级材料 | 速度慢，不适合精密或紧急物资 |
| 低温运输舰 | 氢、氦-3、推进剂等 | 需要冷却、维护和专用装卸 |
| 质量投射器 | 小行星带大宗物料 | 只适用特定路线、方向和货物 |
| 高速快运舰 | 精密组件和紧急补给 | 容量低、燃料昂贵 |
| 星际门户/轨道 | 后期跨区域或跨星系物流 | 巨额基础设施、能源和维护成本 |

运输成本继续用实体约束表达：

```text
运输成本
= 路线与枢纽容量占用
+ 推进剂
+ 维护材料
+ 能源
+ 装卸和转运时间
+ 特殊货物处理要求
```

### 8.4 加工与运输体积

初级加工必须有机会降低货运体积。例如：

- 100 单位混合原矿占用 400 货运体积。
- 粗分选后得到约 40 单位精矿。
- 冶炼后得到约 20 单位合金。
- 最终精密组件只占约 4 单位货运体积。

这些数值是设计示例，不是最终平衡值。必须保留的关系是：加工层级能显著影响运输压力，让“远端粗加工还是运回中心”成为自然选择，而不是依靠生硬的地点加成。

### 8.5 物流界面要求

玩家必须能看到：

- 理论与实际流量。
- 货运类型和容量占用。
- 路线、枢纽和装卸瓶颈。
- 在途数量和预计到达时间。
- 来源保留量、目标量和调度优先级造成的影响。
- 改变生产地点或运输方式后的预测。

## 9. 重点深化方向五：技术代际与研究耗材

### 9.1 三类科技

#### 解锁技术

开放新的设施、资源、船体、模块、运输方式和区域。

#### 改造技术

给既有产业开放新的生产方式，例如：

- 真空冶炼。
- 连续铸造。
- 超导输电。
- 自动化装配。
- 低温分离。
- 无人采掘。
- 质量投射运输。

#### 体系技术

改变整个工业组织方式：

| 工业体系 | 优势 | 代价 |
| --- | --- | --- |
| 中心化工业 | 地球工业效率高、精密加工强 | 长距离物流压力大 |
| 分布式工业 | 远端自治和就地加工强 | 资本品与维护成本高 |
| 大规模吞吐 | 高产量、适合巨构 | 能源和废料压力大 |
| 精密制造 | 材料利用率和高级组件强 | 基础大宗产能较弱 |
| 舰队工业化 | 造船、维修和军需强 | 民用基础设施扩张较慢 |

工业体系允许改换，但必须占用改造时间、建设能力和资本品，避免永久选错，也避免无成本来回切换。

### 9.2 研究耗材

研究继续由工业供给，并扩展为少量具有方向的研究耗材：

- 材料实验组件。
- 推进测试组件。
- 自动化数据核心。
- 舰船原型组件。
- 异常物质样本。

研究耗材必须连接已有产业链，不创建与主经济完全隔离的“科研货币”。

### 9.3 关键技术的验证流程

普通小科技保持简洁。只有会改变工业或前沿能力的关键技术采用完整流程：

```text
理论研究
→ 制造原型
→ 实地测试
→ 开放量产
```

优先适用对象：

- 新型采矿舰。
- 聚变反应堆。
- 质量投射器。
- 大型自动化采掘网络。
- 星际引擎。

## 10. 重点深化方向六：装配方案与舰船工业

### 10.1 已确认的方向变化

普通舰船插件始终是设计定义与 BOM，不是可计数、可库存或可运输的独立实体。玩家管理的是命名装配方案；星港在应用方案时负责制造和安装整套普通插件。

装配方案的正式编辑方式是空白节点画布，而不是预制舰船模型或系统预连线：玩家从“舰船”Tab 拖入一个舰体，从“零件”Tab 拖入组件，并像主板装机一样亲自连接异形接口。舰体是一块由蓝图决定空间拓扑的紧凑装配背板：小型舰体只有少量插槽，大型舰体拥有更齐全、更多的插槽；插槽直接嵌在背板内部，中央圆形位是必需的能源核心，上方为引擎菱形位，底部方形位专用于护甲、护盾、船舱等船体结构件，武器三角与其他特殊插件位分布在左右两翼。连线使用沿网格行进的直角折线；空闲插槽保持灰色空心，连接后才显示类型颜色与实心状态。只有安装类型、接口形状均匹配且未占用的接口可以连接。

目标规则：

- 同一舰体可以保存多个命名装配方案。
- 新方案从空白画布开始；拖入节点不自动建立任何连接，只有玩家完成的连线会被保存。
- 保存前必须校验唯一舰体、零件解锁、接口方向/形状/占用、槽位、尺寸和质量/电力/散热预算。
- 每次应用方案都一次性扣除目标方案中全部普通插件的 BOM；与当前配置相同的插件也不抵扣。
- 制造时间与安装时间在模型中分别记录，当前版本合并为一个连续改装轮次。
- 旧普通插件在拆卸后消失，不进入地点库存，也不占货运容量。
- 取消改装会恢复原装配方案，但已经投入的制造材料不返还。
- 船厂把初始装配方案的完整 BOM 纳入整舰建造成本，完工时直接得到配置完成的舰船。
- 战斗或远征回收的特殊装备仍然是稀有、有限或唯一实体，并保留独立身份。

这一边界避免把装配管理变成零件搬运，同时仍让每次换装产生真实工业成本与时间成本。

### 10.2 舰船制造链

目标造船关系：

```text
船体结构段与整舰材料
+ 初始装配方案全部普通插件的 BOM
+ 特殊装备（仅在方案明确要求且已实际持有时）
→ 船坞总装
→ 插件制造与安装
→ 服役
```

造船厂需要：

- 从本地库存一次性领取船体与初始装配方案所需原料。
- 占用船体生产线和总装能力。
- 消耗重型结构段、船坞机械等资本品或工业材料。
- 为不同尺寸船体配置合适的船坞等级。
- 完成后生成独立舰船身份并直接写入初始装配方案，不生成普通插件库存。

改装必须在星港校验设计、槽位、整套 BOM 和服务能力，然后一次扣料并进入合并的制造/安装轮次。普通插件只记录目标设计；特殊装备继续记录唯一实例的占用关系。

### 10.3 舰体型号与装配角色

科研开发只解锁舰体型号及其造船计划。舰体定义尺寸、槽位、基础货舱和工程预算；实际任务角色必须来自当前装配方案，而不能由舰型 ID 暗中授予。

相比继续堆叠战舰等级，下一阶段优先增加能连接工业、物流和远征的装配角色：

- 专用货运舰。
- 推进剂补给舰。
- 战斗维修支援舰。
- 深空勘测舰。
- 远征指挥舰。
- 专用战斗舰。

工业深化版本首轮实现 5 类后勤/工业角色插件，并提供适合承载这些默认方案的五种舰体型号。任一相容舰体都可以通过换装获得或失去对应职责。

货运舰为舰队或路线提供共享货舱和货运能力，不要求玩家逐艘拖动物品。舰队后勤仍以编组、任务和政策为管理粒度。

### 10.4 工业—舰队闭环

```text
工业提供舰船、整套装配原料和补给
→ 舰队执行运输、勘测和战斗任务
→ 消耗弹药、推进剂、维修物资与服务能力
→ 带回战斗掉落、远征产品、情报和特殊装备
→ 工业修理、补充、改装和扩建舰队
```

任何新装配角色都应至少连接其中两个环节，不能只提供一个新的战力数字。

打捞不再是舰船职业。未来流程是 `入侵事件 → 玩家迎战 → 战场生成有限残骸点 → 打捞/分析消耗共享工作量 → 残骸点消失`。战斗胜利的即时掉落和普通远征产品继续由编队货舱带回；残骸点的后续处理由独立事件/工地系统承担，不读取舰船采矿能力。

## 11. 重点深化方向七：政策层自动化

自动化吸收 Factorio 的目标、蓝图和条件逻辑，但不复制电路接线。

### 11.1 第一级：手动生产

玩家逐条启动配方并设置地点物流，用于理解系统和建立早期工业。

### 11.2 第二级：工业模板

地点一键采用大宗采矿、冶炼、舰船制造、燃料、科研等模板。模板同时设置推荐设施、生产方式、库存政策和自动扩建边界，并允许玩家局部覆盖。

### 11.3 第三级：目标产率计划

玩家声明目标，而不是逐条启动所有生产：

```text
每分钟目标：
钢 40
电子元件 30
维修补给 10
舰船弹药 20
```

系统计算并展示：

- 需要的设施等级和规模阶段。
- 原料缺口。
- 资本品与建设需求。
- 能源、散热和仓储需求。
- 会饱和的物流路线。
- 理论产率与预计实际产率。
- 最短瓶颈链。

这就是聚合尺度下的 Factorio Planner。

### 11.4 第四级：条件自动化

玩家用少量“条件 → 动作”规则管理后期例外：

```text
当钢库存低于 200：
提高钢铁工业优先级

当推进剂库存高于 1000：
暂停水冰加工

当路线利用率超过 90%：
优先运输精密组件，降低原矿优先级

当电网备用低于 10%：
关闭低优先级巨构生产
```

规则系统要求：

- 条件和动作采用有限、可组合的模板，不开放脚本执行。
- 每次自动动作有日志和原因。
- 可以设定冷却时间，防止规则抖动。
- 手工锁定的项目不会被自动化覆盖。
- 自动化不能绕过库存、建设、能源和物流规则。

后期主要操作应转为设定目标、处理警报和调整例外。

## 12. 重点深化方向八：勘测、地点差异与区域身份

### 12.1 新区域内容标准

每个新区域至少引入：

1. 一种新资源或新副产物。
2. 一种新环境约束。
3. 一种新生产方式。
4. 一种新运输解决方案。
5. 一种新的舰船装配角色。
6. 一层新自动化能力。
7. 一个明显的视觉地标。

如果区域只增加更高品位资源和更强敌人，不满足新增区域标准。

### 12.2 现有区域工业身份

| 区域 | 目标工业身份 |
| --- | --- |
| 地球轨道 | 物流、建设、精密工业和总装中心；结构空间昂贵 |
| 月球空间 | 真空冶炼、低重力制造和早期固定采掘 |
| 小行星带 | 大宗采矿、远端粗加工、质量投射和高维护压力 |
| 木星系统 | 气体采集、推进剂、聚变燃料、强辐射与重力约束 |
| 外太阳系 | 低温工业、长周期运输和自治设施 |
| 深空 | 特殊物质、高维护、高风险，必须依赖远端自治 |

### 12.3 勘测循环

```text
远程观测
→ 粗略资源判断
→ 派舰勘测
→ 确认品位和危险
→ 深度勘测
→ 开放固定网络或特殊生产方式
```

勘测必须实际改变采矿部署、地点建设、物流或生产方式选择，而不只是填充图鉴。

### 12.4 资源枯竭原则

- 基础资源点永久存在，避免经济软锁。
- 可以增加高品位、有限储量的临时矿区。
- 临时矿区枯竭后触发重新勘测、舰队迁移和物流调整。
- 固定设施在矿区枯竭后应允许迁移、改造或保留较低基础产出，减少惩罚性重复建设。
- 动态矿区必须等自动化、警报和物流重规划工具成熟后再正式加入。

## 13. 巨构：工业战争而不是后期进度条

### 13.1 核心要求

每个文明级工程必须：

- 消耗不同工业体系的产出。
- 与设施、舰队和其他巨构争夺建设能力、能源和物流。
- 在中间阶段就产生部分系统效果。
- 在地图或地点场景上持续成长。
- 改变已有玩法，而不只在 100% 时给数值加成。

### 13.2 恒星能源工程示例

| 阶段 | 可能效果 |
| --- | --- |
| 10% | 提升太阳系能源预测和电网稳定 |
| 25% | 开放远距离输能 |
| 50% | 降低高级能源维护 |
| 75% | 支持大规模自动工业 |
| 100% | 成为星际工程能源前置 |

### 13.3 深空阵列示例

随阶段逐步：

- 提高勘测范围。
- 降低远征情报不确定性。
- 改善深空路线稳定性。
- 开放星际目标定位。
- 最终支持星际航行。

### 13.4 巨构战略选择

巨构不能按固定顺序全部无脑开工。玩家应真实面对：

> 先完成能源工程扩大生产，还是先建设深空阵列推进终局？

界面必须展示每个工程对当前工业、物流、能源和其他建设项目的机会成本。

## 14. 美术与 UI 的三层结构

表现层首先服务于系统理解，其次才是装饰。

### 14.1 第一层：星系战略地图

地图主要显示：

- 舰队移动。
- 物流方向和真实流量。
- 路线与枢纽拥堵。
- 正在建设的地点和工程。
- 危险、能源、资源、工业和情报图层。
- 巨构阶段。
- 区域警报。

地图借鉴 Stellaris 的战略尺度和 Outliner 思想，但不照抄布局。

常驻 Outliner 优先显示：

- 被阻塞的工业。
- 缺少补给或维修的舰队。
- 正在建造的项目。
- 研究进度。
- 物流拥堵。
- 远征状态。

### 14.2 第二层：地点工业场景

每个地点使用 2D 或 2.5D 代表性场景表现工业身份：

- 船坞和设施规模。
- 工业灯光或模块密度。
- 货运流量。
- 采矿舰和固定网络活动。
- 巨构结构。
- 建设进度和环境特征。

不渲染每一家工厂，不进入单机布局；只呈现足以说明真实状态的代表性模拟。

### 14.3 第三层：生产与装配细节

生产设施统一展示：

```text
输入 → 生产方式 → 输出
```

同时展示：

- 理论产率与实际产率。
- 首要瓶颈。
- 能源和散热。
- 本地与跨地点物流。
- 库存可维持时间。
- 废料、副产物和维护。
- 改变生产方式后的预测。

舰船装配页使用可平移缩放的空白节点画布、舰船/零件拖拽 Tab、异形接口、实际槽位、可用插件设计、特殊装备实例、整套 BOM、质量、电力、散热、货舱和任务适配度，不依赖舰船模型或纯列表。画布节点位置和玩家连线属于命名装配方案并随存档持久化。装配画布必须占满造船页面下方剩余工作区，并在窗口尺寸变化或执行“显示全图”时把完整装配图纳入视野；“舰船”Palette 只列出玩家已经解锁、当前能够用于装配的舰体型号，不展示尚未拥有使用权的数据库条目。

### 14.4 分辨率、界面缩放与画布缩放

游戏不以 1440×900 作为固定成品画布。1440×900 只是桌面布局的设计基准，窗口放大后容器继续吸收新增空间；同时提供独立的界面缩放，让高分辨率全屏下的文字和操作区域不会停留在小窗口尺寸。

界面缩放采用以下正式规则：

- 新安装默认 125%。
- 玩家可选择 100%、125%、150%、175% 和 200% 五档。
- 字体按所选比例完整缩放；按钮高度、留白、栏宽和面板圆角使用较温和的布局比例同步增长，避免把 1440×900 的有效工作区挤空。
- 125% 以上的工作区导航允许自动换行；高倍率下可隐藏顶栏的重复状态摘要，但保存、速度、语言、界面缩放和重开等主操作必须始终可见。
- 当物理窗口无法同时容纳左右侧栏和中央画布时，两侧栏自动变为互斥抽屉：默认保留资源栏，展开情境检查器会收起资源栏，反之亦然；大窗口仍可同时展开两栏。
- 该偏好保存在设备本地 UI 配置中，不进入玩法存档，也不影响模拟结果。

界面缩放与画布缩放必须严格分离：

```text
界面缩放
→ 字体、按钮、间距、侧栏、检查器

地图/生产/星球/装配画布缩放
→ 世界内容、节点、方格地块和玩家视野
```

禁止通过放大根 `Control` 或全局拉伸整个 viewport 来实现界面缩放，因为这会同时放大星系地图、星球地块和生产画布，破坏可视范围与交互坐标。星系地图、工业网络、舰船装配和行星方格画布分别保留自己的平移、缩放、显示全图与缩放复位逻辑。

UI 验收至少覆盖 1440×900、1920×1080 和 2560×1440；100%—200% 各档必须保证核心导航和全流程操作仍可到达。较小窗口可以出现页面内部滚动，但不能依赖把字体缩回不可读尺寸来维持布局。

## 15. 下一阶段：Industrial Depth Update，工业深化版本

第二恒星系暂时不做。下一阶段先在现有太阳系内完成一个范围受控的工业深化版本。

### 15.1 进入工业深化前的基础门槛

以下工作必须与工业深化同步优先完成，或先于大规模内容扩张完成：

1. 从默认新存档到第一次星际远征的无作弊黄金路径。
2. 木星、外太阳系、深空和巨构阶段的细分引导。
3. 统一的“为什么停工”瓶颈诊断。
4. 舰队、工业和物流页面的信息架构与布局验收。
5. 开发测试倍率与正式游戏节奏分离。

新增复杂度必须建立在玩家能够看见并理解现有系统的基础上。

### 15.2 内容范围

工业深化版本的目标规模：

- 8–12 种资本品。
- 4 条重点产业链。
- 12–18 种生产方式。
- 4 类地点工业专精。
- 3–5 种货运方式。
- 5 类装配驱动的后勤/工业角色及配套舰体型号。
- 装配方案的整套制造与安装。
- 一个目标产率规划器。
- 一个地图物流图层。
- 所有设施等级扩建进入工程队列。

重点产业链：

1. 钢铁与大型结构。
2. 电子与自动化。
3. 能源与散热。
4. 舰船、维修与物流设备。

### 15.3 推荐内部交付顺序

#### 阶段 A：闭环与可解释性

- 全流程黄金路径。
- 后期引导。
- 统一瓶颈诊断。
- 正式/测试节奏配置。
- 核心页面布局修正。

#### 阶段 B：工业资本与建设

- 资本品内容。
- 扩建项目化。
- 建设能力和工程竞争。
- 工业规模阶段。
- 地点容量和专精。

#### 阶段 C：生产与物流选择

- 四条重点产业链的生产方式矩阵。
- 货运属性和 3–5 种运输方式。
- 加工体积变化。
- 目标产率规划器。
- 地图物流图层。

#### 阶段 D：舰船工业与自动化

- 装配方案、整套 BOM 扣料和旧模块库存迁移。
- 五类装配驱动的后勤/工业职责及配套舰体型号。
- 星港制造/安装轮次和特殊装备占用。
- 条件自动化。
- 研究原型和实地测试流程。

### 15.4 范围控制

工业深化版本不同时引入：

- 第二恒星系。
- 人口、工资、市场和政治。
- 逐机器工厂布局。
- 手工货船驾驶或逐船货物拖放。
- 即时战术微操。
- 全面资源枯竭。

## 16. 第二恒星系的长期方向：工业自举

第二恒星系不是“再复制六个地点”，而是后续大型阶段的 `Industrial Bootstrap`。

首次星际远征只能携带有限负载：

- 采矿设备。
- 基础反应堆。
- 自动化工坊。
- 维修舰。
- 建设舰。
- 防卫舰。
- 初始资本品。
- 特定生产模块。

核心问题：

```text
选择远征负载
→ 建立前哨
→ 建立能源
→ 建立采矿
→ 建立维修
→ 建立基础工业
→ 实现本地自给
→ 建立跨星系物流
```

负载选择必须产生真实后果：

- 能源不足会阻止工业启动。
- 维修能力不足会让远征资产逐渐失效。
- 精密设备不足会让新星系只能生产粗级材料。
- 防卫不足会提高前哨和运输风险。
- 资本品不足会限制自举速度。

当新系统成熟后，太阳系逐步转为后台自动工业，玩家把主要注意力转向新前沿。

该方向保留，但不进入下一阶段工业深化版本。

## 17. 明确不做与暂缓内容

### 17.1 不做：设施内部的机器级微操

- 行星本身就是可平移、缩放和分块加载的工厂沙盒地图。
- 玩家可以铺设宏观货运线路、管道、电网或运输走廊。
- 玩家放置大型采掘场、冶炼区、装配区和仓储区，不进入建筑内部逐台摆放装配机。
- 远景按区域和网络管理，近景才显示 1 米格线与精确占地。

生产网络同时由空间实体、端口、线路、配方、设施规模、产率目标和物流政策表达。

### 17.2 不做：人口、工资、价格和政治模拟

- 不建立 Victoria 3 式人口就业。
- 不建立工资、阶层和消费市场。
- 不用市场价格替代真实资源与运输。
- 不在当前定位下加入派系、外交和政治大系统。

### 17.3 不做：手工货运微操

- 不要求玩家逐艘拖拽物品。
- 不要求手工驾驶运输舰。
- 货运舰和运输基础设施提供共享能力，由策略和调度规则控制。

### 17.4 不做：即时战术微操

战斗继续由工业准备、舰船装配、前中后排、舰队后勤、学说和撤退策略决定。优先建设预估、轻量表现和战后分析，不转向实时点技能。

### 17.5 暂缓：全面动态枯竭

可以设计有限高品位矿区，但必须等待勘测、自动化、警报和物流重规划成熟。基础资源保持永久，防止软锁。

### 17.6 暂缓：第二恒星系

先证明太阳系完整流程，完成工业深化和界面可解释性，再进入工业自举阶段。

## 18. 数据与架构方向

后续实现应延续数据驱动和事务式命令结构，并采用分域库存权威：方格世界内由实体缓存/仓储/施工暂存持有物资，尚未迁移的跨地点系统继续使用 Location Inventory；两者之间只能通过显式装卸事务转移，不能镜像。

需要新增或强化的数据概念包括：

- `factory_world`：有限米制边界、seed、generator version、Chunk 参数、实体、线路、建设订单与 Tile 差量的方格世界聚合。
- `grid_entity`：固定矿体或具有宏观 Footprint、端口、缓存、功率和运行状态的玩家设施。
- `factory_recipe`：方格机器的输入、输出、周期和兼容设施，不再由 UI 点击直接结算。
- `factory_link`：RESOURCE / CARGO / POWER 本地连接及其吞吐、优先级和实际流量。
- `factory_construction_order`：占用确定 Footprint、持有已交付材料并消耗真实工时的普通设施建设。
- `capital_good`：资本品类别、代际和适用工程。
- `domain_project`：科研、舰船和远征保留各自项目模型；巨构采用方格建设或专用空间工程实体，不再复用已删除的通用地点级 Construction Project。
- `facility_scale_stage`：设施等级对应的规模阶段与能力变化。
- `industrial_specialization`：地点专精、改造成本和效果。
- `production_method`：输入、输出、速度、效率、能源、散热、废料、维护、货运体积和能力要求。
- `freight_class`：货物类型和处理要求。
- `transport_mode`：适用货类、容量、速度、燃料、维护、能源和基础设施要求。
- `module_instance`：标准与特殊模块的实体副本、地点、安装占用和状态。
- `rate_plan`：地点或星系目标产率及预测结果。
- `automation_rule`：有限条件、动作、冷却和执行日志。
- `survey_intel`：资源置信度、品位范围、危险和深度勘测结果。

关键不变量：

- 所有实体资产有且只有一个明确所有者或地点。
- 在途货物不会同时存在于来源库存和目标库存。
- 已安装模块不会同时存在于仓库。
- 工程只消耗真实地点库存和实际送达物料。
- 自动化只能调用正常玩家事务，不能绕过规则。
- 任何主线关键物品都有确定性、可重复来源。
- 内容校验器必须检查新增引用、经济闭环、模块所有权和解锁依赖。

## 19. 工业深化版本完成标准

只有同时达到以下条件，才能认为工业深化版本完成。

### 19.1 全流程

- 新存档无需测试注入资源即可到达第一次星际远征。
- 全流程测试能记录每阶段时间、库存、产率和阻塞原因。
- 10 倍测试模式与正式平衡模式使用同一套规则、不同参数。

### 19.2 工业

- 至少四条重点产业链存在有意义的生产方式选择。
- 扩建设施会真实竞争建设能力和资本品。
- 工业规模阶段带来能力变化，而不只是连续百分比。
- 至少四种地点专精能形成不同的合理布局。

### 19.3 物流

- 货物具有可理解的货运类型和容量占用。
- 至少三种运输方式存在明确适用场景。
- 远端粗加工与中心精炼在不同条件下都可能合理。
- 地图能够显示真实流量、在途、拥堵和关键警报。

### 19.4 舰船工业

- 普通舰载插件只作为装配方案设计和 BOM 存在，不进入库存或运输。
- 特殊装备实例在安装、拆卸、改装和报废中遵守唯一归属。
- 舰体不直接授予任务能力；至少五类装配角色连接物流、采掘、维修、建设或勘测。
- 舰队补给和维修持续消耗工业产出。

### 19.5 自动化与可解释性

- 玩家可以声明目标产率并看到设施、原料、能源、物流和建设需求。
- 任一停工状态最多两次点击即可看到根因。
- 自动化动作有原因、日志和手工覆盖边界。
- 后期操作重心从逐条启动生产转为目标、警报和例外处理。

### 19.6 表现层

- 星系地图能够显示舰队移动、物流流向、拥堵和建设状态。
- 地点场景能辨识区域工业身份和规模。
- 生产页能同时显示输入、方式、输出、理论/实际产率和首要瓶颈。
- 舰船装配页能表现插件设计、特殊装备实例、整套 BOM、槽位和任务适配度。

## 20. 一句话方向

> **以地点库存和真实物流为底，以资本品和建设能力限制规模，以生产方式和技术代际创造选择，以实体舰船连接工业与前沿，再通过政策自动化和代表性视觉让玩家管理并看见一个跨行星工业文明。**
