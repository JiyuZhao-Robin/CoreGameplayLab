# 行星开发枢纽与生产建筑归并

更新：2026-09-11。

正式开局只部署新的 FUE5 太空电梯 + DSP 停机坪组合建筑。沿用 `grid_planetary_core` 存档身份，提供 2,000 共享仓储容量、4 架无人机、64 格圆形覆盖和 400 kW 启动电力。旧核心图像已退出运行适配器。首次落地发放两矿机、两电弧炉、一制造工厂，仅领取一次；独立无人机塔仍可制造，用于扩大覆盖，普通仓库仍用于增加共享库存容量。

## 当前建筑与配方

| 保留建筑 | 合并内容 |
| --- | --- |
| 动画采掘设施 `grid_surface_mine` | 普通矿机、低温与奇异物质采掘、抽油、抽水；按实际资源保留速度、功率与科技条件 |
| 动画电弧炉 `grid_arc_smelter` | DSP 电弧熔炉、位面熔炉；开局铁铜冶炼保持完整 |
| 动画制造工厂 `grid_engineering_works` | 旧电子厂、装配阵列、三代装配机、施工中心和矩阵成品制造 |
| 动画燃料精炼厂 `grid_dsp_oil_refinery` | 现有炼油配方 |
| 动画化工处理站 `grid_dsp_chemical_plant` | 量子化工厂、分馏和粒子对撞机的物料配方 |
| 动画热能工厂 `grid_dsp_thermal_power_plant` | 现有热能燃料发电 |

共 16 个重复建筑退出活动目录，它们的建筑成品退出物品目录，普通配方转向保留的建筑。原始数据分片保留来源记录，内容加载时通过 `FactoryBuildingCatalog` 统一归并；不能直接把分片中的历史定义数量当成实际建造栏数量。

电弧炉按此前批准的冶炼链保留，因此生产建筑为用户列出的五类加独立电弧炉。研究消耗、发射、轨道采集、星际运输和终局项目保留独立装置；太阳能、风能、地热、核聚变、人造恒星和储能属于不同电力机制，本次不削除其能力。制造工厂承接电子与装配设施的前置能力；装配能力仍在重工业科技解锁后生效，独有高级配方保留科技要求。

## 运输与旧存档

- 普通材料保持累计 10 件取货、十批配方原料补货目标。**建筑成品有 1 件即可取回枢纽**，避免第一次扩张被批量门槛卡住。
- 旧建筑实例原位映射，保留实例编号、占地、生产进度和缓存；不在加载时扩大占地挤入相邻建筑。
- 库存、预留、无人机和星际在途货物统一转换成品编号；旧新编号同时存在时合并数量，预留不变成额外实物。
- 已在运行的旧建筑制造配方保留原投入清单、时长和进度，产物改为新建筑；只供存档延续，不能从菜单新选。
- 旧矩阵生产研究站改为制造厂，纯研究站保留。旧建造幽灵转换为对应的新建筑成品；实际部署重新检查新占地，放不下时保留幽灵和成品。
- Location 仍是唯一行星仓储权威。历史归档、来源信息及指令幂等凭据不随物品替换改写。

## 本次验证

主代理已串行运行并通过：建筑目录、归并迁移、建筑成品部署、开局内容、Factory 模拟、无人机集成/运输/预留、内容规划、核心完整性和资产守恒检查。新增迁移用例验证三次往返中 54 件实物守恒、原始字典不变、旧配方通过无人机补料后完成，以及旧版误标为固体的原油无法绕过科技条件。

界面已通过无人机 UI、太空电梯美术、固定布局 policy / scale / window-matrix、双语目录、UI Domain 和操作注册表的聚焦检查；正式场景太空电梯截图已生成。未运行完整发布总门禁或 J1–J10。
