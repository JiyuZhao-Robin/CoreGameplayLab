# 核心游戏循环

## 从新存档到终局

```text
发现并勘测地点
→ 选择资源点与开采方式
→ 建立永久采掘、能源、仓储和物流
→ 原矿直运或远端粗加工
→ 冶炼材料与制造资本品
→ 扩建工厂、设备、能源、散热和港口
→ 设计并制造运输、战斗、舰队支援和勘测舰船
→ 启动研发项目并解决工程门槛
→ 用新材料和新方法重组旧产业
→ 建立远端工业基地
→ 诊断库存、维护、能源和物流瓶颈
→ 扩张全恒星系工业网络
→ 建造唯一的恒星能源巨构
→ 调试投产并完成本版本终局
```

## 玩家做的决策

- 在哪里生产：资源禀赋、真空/大气、重力、太阳辐照、辐射、维护严重度与运输时间共同决定方案经济性。
- 如何生产：不同 Production Method 在原料、能源、散热、设备、质量和吞吐之间形成取舍。
- 扩什么：库存与 Demand Registry 暴露真实的持续需求和脉冲需求；Planner 只分析，不替玩家建设。
- 如何补给远端：可以增加运输与仓储，也可以建立本地能源、维护品和初加工体系。
- 如何加速终局：巨构速度取决于全系统材料、资本品、运输、建设能力和能源，而不是固定时间锁。

## 系统做的工作

- 有输入、能源、散热和库存空间时自动运行已配置生产线。
- 满仓自动停机，释放空间后自动恢复。
- 记录每一项需求、预留、运输和消耗的来源。
- 给出 Primary Blocker、Root Cause 和最短 Upstream Chain。
- 为商品/小时、舰船/月、研发阶段和巨构阶段提供只读 BOM、工厂、能源、散热、仓储、质量/体积物流和地理潜力规划。
- 对已授权的暂停、恢复、路线策略和项目优先级执行有限自动化。
- 在 ×1、×10 与离线推进中使用相同的事件边界模拟。

## 终局工程

当前版本只有一个 Megastructure：`stellar_energy`。它由研究与选址、前进基地、锚定基础、主体框架、能源骨架、主功能系统、集成和调试八个阶段组成。每个阶段使用正常库存、建设、物流、能源和维护系统，最后展示全项目材料、资本品、运输、峰值建设吞吐、峰值功率、工期和主要供应地点。
