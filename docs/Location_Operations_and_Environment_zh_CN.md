# 地点运营面板、勘测与环境影响

本轮将地点概念图落为可操作的 Godot 界面：深蓝底色、青色/琥珀色状态、既有建筑美术、四个指标卡、左右分栏资源/工业/库存/任务，以及底部环境摘要。不是整张概念图贴在游戏上。

## 玩家流程

1. 星系地图点击可到达但尚未发现的地点，例如月球区域。
2. 选择现有勘测舰；开局 Pioneer 可以直接通过面板编队后执行初次探测。舰船能力、所在地、占用状态和材料不足会限制出发。
3. 探测按实际游戏时间推进，扣除对应物资并占用舰船；完成后回收舰船占用，公布对应情报。
4. 完成勘测后可初始化该地点的物理工厂。情报预览和实际资源区共用确定性生成逻辑，不会因为看一眼页面就生成工厂或免费建筑。
5. 在运营面板查看资源、实际产物、缺电/缺料/缺燃料告警与任务；直接打开对应工厂、部署幽灵、库存、物流或舰队。地球未落地时，工业和任务空态都引导部署核心。

勘测不是战役区域解锁。初次探测允许访问前一区域已解锁的下一目标；后续战略航线仍遵循自身推进条件。

## 情报层级（当前物理 Factory 合约）

| 状态 | 可见内容 |
| --- | --- |
| UNKNOWN | 地点身份；无资源或精确环境数据 |
| DETECTED | 资源类别、潜力区间、辐射、距离/建设难度区间 |
| SURVEYED | 资源类型、当前基础品位与映射潜力、完整环境；允许初始化工厂 |
| DEEP_SURVEYED | 额外公开精确资源区位置和尺寸 |

这里明确采用现有物理资源区的基础品位/潜力合约，取代早期工业深度规划中“普通勘测只给品位范围、深勘测给高级潜力”的未落地设想。不额外伪造另一套资源储量、工法产量或高级潜力数字。

## 环境是实际规则，不只是说明文字

这些系数属于可调节的游戏平衡规则，不是物理模型。

- 太阳能输出 = 额定输出 × √日照通量。无日照时为零；非太阳能发电不受此修正。
- 运行耗电 = 额定耗电 × 温度修正 × 辐射修正 × 重力修正 × 大气修正。
- 温度耗电系数：受控 1.00、冷热循环 1.10、寒冷 1.15、极寒 1.30、极热 1.35。
- 辐射耗电系数：低 1.00、中 1.05、高 1.15、极高 1.30。
- 重力耗电系数 = 1 + 重力 × 0.10；气态巨行星大气系数 1.15，其余 1.00。
- 普通建筑已改为成品部署，不受旧施工工时和施工速度系数影响；地形合法性、建筑库存和道路供电仍是实际约束。建设难度作为地点情报保留，不能展示成尚不存在的部署工期。

环境输入由 Location 投影到 Factory；系数集中在 `FactoryEnvironmentEffects`，供电图、建筑详情和地点汇总共用它。DSP 太阳能板与本项目太阳能阵列使用相同日照规则；核心发电不随日照变化。旧施工系数仅为兼容数据，不再显示为普通建筑施工效果。缺失环境的独立领域测试使用中性值。

地点供电卡统计该地点的物理工厂，顶栏文明电力还包含其它既有文明系统，二者范围不同。工业行保留全部配方输出（包括副产物），逐项速率可查看提示。

## UI 与状态边界

- `Game.location_operations_snapshot` 发布协议版本 1 的分离快照；新组件不直接修改游戏状态或调用模拟器。
- UI 发出操作意图，Main 统一通过现有 Game 命令执行。
- 固定 1920×1080 逻辑画布，4K 输出统一两倍缩放；只有命名列表内部滚动，页面本身不滚动。
- 进度从模拟器刷新，同一地点常规刷新保留面板、任务行和玩家选择，不重新搭建整个页面。
- 同步维护中英文本；截图和运行日志留在临时目录，不作为游戏资产提交。

## 功能验证入口

### 独立仓储与卡片（2026-09-10）

- 资源与本地库存按用户提供的 Anno 1800 仓库截图排列：固定十二列等大正方形，均分所在面板的逻辑可用宽度，扣除间距和可见滚动条；第十三项换行，不再将大量可用宽度留空。低饱和蓝灰色格（与主界面协调，替代米色）内以物料美术为主体，左下显示浅色数量，右下显示实际盈亏的绿色 ▲/红色 ▼（平稳或无样本时为灰色 ▶），右侧绿色细竖条由下往上表示该物资自己的容量占比。零库存显示 0；未知资源不泄露数量、库存或趋势。名称、精确数量/容量及产速只在悬停提示/无障碍描述中显示，大数在格内缩写为 k/M。此方案替代上一版无数字的整格水杯；200% 显式字体设置和物理窗口缩放均不改变十二列或正方形比例。
- 正式物料美术使用内置 ImageGen 生成的透明 `assets/ui/location/generated/material_icons_v2/material_icons_atlas.png`，8×4 共 32 格（31 个物料/类别图与 1 个未知扫描图），取代旧的代码几何占位图。开局 17 种物资各有不同图标；后期同族物料显式复用对应格。精确提示词与来源见同目录 `PROMPT.md`，运行时映射集中在 `location_item_icon.gd`；全页共用一张纹理并缓存切片，不在每次刷新中创建纹理。
- 未揭示资源连悬停提示、无障碍描述、水位和趋势也不泄露隐藏的物料名/数值。鼠标悬停时保留节点与焦点，但已有物料格的水位、方向和提示继续实时刷新。
- 库存列出已解锁配方物资、建筑成品（包括零库存），以及实际持有、已揭示或在途的物资。数量只读取 Location 唯一共享库存；机器输入/输出缓存、道路在途和舰船货舱不计入仓储卡片。在途数量另作提示，不提前记入库存。
- 每种物资拥有独立仓位。新游戏地点基础容量每种 200；工厂仓库的 `inventory_capacity` 同样按每种物资计算。满铁矿不阻止铜矿入库，道路入库预留只占对应物资容量。机器和舰船仍使用自己的物理缓存/货舱限制；退休路由器不再出现在建造列表。
- 地点容量工程的分类额度代表该类别每种物资的额度；工厂 STORAGE 为所有类别提供对应独立额度和道路装卸接入。道路自动在机器与共享库存之间搬运，不再提供手动仓库导入导出。
- 旧库存不删除；超额物资可继续消耗但不能增加，不挤占其它物资。旧有显式容量配置保留，未添加存档迁移链。
- 绿色 ▲ / 红色 ▼ 使用最近约 30 秒模拟时间的 Location 实存净变化，至少取得 1 秒样本后显示；无样本和稳定库存显示中性。暂停时间不创造速率；同地点仓库共享库存，不存在仓库之间的重复转账。道路向机器供料或把产物送回库存会产生真实净变化；重开游戏清空显示层样本。
- 工业卡补齐建筑图、产品、实际产速、电力与状态；任务卡补齐按类型选择的设施图、动态进度、剩余时间与阻塞原因。空态按钮直接进入对应地点的建设/初始化/探测，不打开不存在的工厂。
- 其它仓储汇总改为满仓物资种类与最高仓位填充率，不再用一个共享仓库进度条误导玩家。

仓储定向测试为 `item_warehouse_capacity_test.gd`、`location_inventory_trend_test.gd`、`location_stock_projection_test.gd`；卡片、动作、情报边界和 200% 字体下的内部列表高度由 `location_operations_workspace_test.gd` 覆盖。历史端口连线夹具不作为道路玩法的通过证据。

物料美术由 `location_material_art_test.gd` 验证（真实图集、透明度、32 格有效像素、内容 ID 映射、开局图标互异、切片缓存）。Workspace 测试覆盖十二列铺满/第十三项换行、方形、数量与右侧 0/50/100% 容量条、真实 hover 中刷新、未知信息遮蔽和无障碍入口；不因此重跑全量玩法链路。

勘测与环境测试入口为 `location_operations_flow_test.gd`、`location_operations_workspace_test.gd` 和 `factory_environment_effects_test.gd`。旧流程夹具中的现场施工进度/工期断言需要随成品部署同步，不能自动视为当前通过。`content_sync_flow_test.gd` 与 `content_sync_ui_test.gd` 专门检查核心开局、真实库存、太阳能与新界面文案。
