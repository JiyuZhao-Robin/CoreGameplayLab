## 已批准的后续工作

1. **区域蓝图**：支持区域选择、旋转、资源锚点、建筑幽灵和原子部署；适配无人机覆盖，不再包含道路；不得用机器配方复制冒充完成。
2. **自然地表工作已暂停**：山脉、水域、森林、自然对象采集、山体开挖和巨型挖掘机均暂不继续。当前只保留平地与现有矿脉；历史要求保留在[地表记录](./Earth_Terrain_zh_CN.md)，不能自动恢复为实施任务。
3. **无人机物流深度**：圆形范围和真实飞行精灵已接入；后续可扩展运力与覆盖升级。道路装卸与道路等级退出当前计划。
4. **性能与平衡**：对最大世界、多塔覆盖和大工厂做可复现负载基准；复核无人机任务上限、载量、飞行速度和服务半径。
5. **旧端口清理**：在不影响存档归一化的前提下继续清理内部 CARGO/POWER 兼容路径、过期测试夹具与旧文案。

## 待用户设计确认

- **有限矿量**：当前资源持续开采。若改为有限或高品位矿区，必须先决定是否会耗尽、如何避免软锁、勘测和物流重规划如何反馈，以及大地图上的状态/性能预算。
- **资源地理分层**：当前 Earth 生成全部 15 种 DSP 原料，气态巨星额外有氢、氘和可燃冰。是否改为“地球基础、其它星球进阶、外层稀有”尚待用户决定；在决定前不得声称已实现资源稀缺性或行星专精平衡。

## 验收原则

- 每项实施只运行受影响的标准聚焦测试；完整发布脚本与 J1–J10 runtime 仅在明确请求时运行。
- 所有新测试必须引用当前无人机物流、成品部署和 1920×1080 UI 契约，不能重建旧聚合工业路径。
