# Helios Core Gameplay Lab

这是从主项目拆出的独立 Godot 项目，也是 Walking Skeleton 的实现目标。它只保留玩法规则、内容数据、存档逻辑和纯控件操作界面，不依赖主项目中的图片、模型、Shader 或 UI Art Pack。

当前 Save Schema 为 27。旧 Lab schema 24 的全局库存会在读取时一次性迁移到 `earth_orbit` Main Base；schema 25–26 的 Location、物流与在途 Shipment 会保留，并迁移到普通模块 BOM / 稀有装备实体和舰船生命周期语义。

## 直接启动

1. 打开 Godot 项目管理器，点击“导入”。
2. 选择本仓库中的 `project.godot`，然后点击“导入并编辑”。
3. 按 **F6** 运行当前场景，或按 **F5** 运行项目。

也可以在仓库根目录运行：

```bash
godot --path .
```

## 当前玩法流程

1. 在左侧产品导航的 **星系地图** 上点击已知轨道节点，进入地点的总览、资源、工业、物流和工程页面。
2. 在 **舰队** 将已经安装采矿激光的初始勘探船调入采矿舰队。
3. 在 **前线作业** 启动近地永久采集点，并使用顶部 **10×** 或 **50×** 加速。
4. 在 **工业与建设** 的“生产配方”工作区将混合粗矿分离成铁矿和铜矿，分别精炼成铁锭和铜锭；再用 **2 铁锭 + 1 铜锭** 组装结构框架。
5. 保留第一套结构框架，再准备 **4 铁锭 + 2 电子元件**，进入“设施建设”建造轨道铸造厂。再生金属只是可选回收物，不再是核心建筑的必需材料。
6. 初始工程制造中心可直接用铁锭和铜锭持续组装基础电子元件。建立研究中心后推进科研；在 **星港与舰队** 完成造船、改装、前列/中列/后列编队与补给，再进入远征。
7. 在后期的 **文明工程** 页面交付四项阶段化巨构，完成第一次星际发射。

核心规则现已覆盖：地点独立库存、受枢纽和航线吞吐约束的多跳物流、化学推进货运到星际门的物流科技链、矿点潜力/品位/工艺/风险效率链、工业等级与能源/冷却/结构/仓储约束、可切换投入/产出/能耗/废料/吞吐的生产工艺、产品熟练度与工业经验、六类工业模板及策略化自动扩建、舰船配置物料清单/批量造舰/特殊装备实体、现役/储备/封存/再服役/拆解归档、三线编队战斗、独立武器循环、逐舰伤害结算、穿透/绕后与点防御/电子战、单舰经验与战绩、作战条令/撤退策略、阶段化巨构和后期后台生产。

经济闭环由内容校验器和自动化测试共同约束：所有战略消耗品必须有可重复来源；所有常规工业产物必须有后续用途或回收路径。结构框架、电子元件、普通舰船模块、维修物资、反应堆部件和数据核心都具有确定性制造路径，战斗掉落只提供额外收益，不再承担主线唯一入口。

左侧的“当前引导”会根据实时状态给出下一步。所有按钮都调用复制后的真实核心命令，不是伪流程。
