PNGs and Lua metadata are unchanged copies. Runtime applies copper-gold mask tint, additive working light, and proposed placement sizes. 30 fps is a local preview choice. No production replacement has been approved.

Runtime and `python tools/import_building_candidates.py --check` use only project files. Re-import requires an explicit `--source-root` pointing to the recorded upstream checkout.
