# HELIX-01 original miner prototype

Original procedural 3D mining-rig model authored for this project with Codex.
Geometry, mechanical animation and materials are generated by
[`tools/build_helix_miner.py`](../../../tools/build_helix_miner.py).
No Hurricane, Nullius or other reference building mesh/image was used to make
the model. This is a first authored asset prototype, not final game art approval.

## Editable deliverables

- `source/helix_miner.blend`: native Blender scene, bevelled separate parts,
  procedural PBR materials, lights, orthographic camera and animated timeline.
- `helix_miner.glb`: self-contained 3D interchange model, 178 exported meshes,
  one continuous animation with five channels for the drill, feed carriage,
  hydraulic piston and cooling fan. Standard PBR base values are exported;
  Blender-specific procedural material nodes remain in the `.blend` and bake.
- `sprites/`: 108 transparent 512×512 body frames plus separate static shadow,
  accent mask and emissive passes. The low-opacity mask selects static armour;
  moving mast occlusion is excluded from the mask.
- `manifest.json`: explicit clips, layer rectangles and ground anchor computed
  from the camera projection. The 4×4 footprint is a calibration choice only.
- `provenance.json`: generator-script hash and per-file SHA-256 for the model
  and baked images. It detects changes; it does not promise bit-identical Cycles
  rendering across machines, GPU drivers or Blender versions.

The ledger is written only after a complete `--bake` run exports the models and
all frames. The CLI requires either `--bake` or `--preview`; preview mode writes
only an ignored review image and cannot refresh the asset ledger.

The native source folder has `.gdignore` so Godot does not require Blender to
import a `.blend` whenever the game starts. Godot consumes the GLB and frame PNGs.

## Animation

30 fps master timeline: startup frames 1–24, working 25–84, shutdown 85–108.
The 2D preview consumes those ranges as three clips. Work lasts two seconds per
loop; a stop request waits for the loop endpoint, then retracts over 0.8 seconds.
Startup and shutdown requests made during transitions take effect at the next
matching pose. Scrubbing pauses playback. None of these clocks drive inventory
or production simulation.

The model has a solid helical cutter, a translating feed saddle, chrome guide
rods, hydraulic feed piston, braced gantry, four levelling jacks, power enclosure,
cooling fan, hoses, deck grating, handrails, fasteners and identification plates.

## Rebuild / preview

Used Blender **4.5.9 LTS**, portable official Windows build. Download archive
SHA-256: `41da973b9bf95bb312cbeff4d1982feb13259b43c821686b9bafea4dfe5477cf`.
Archive and checksum came from `https://download.blender.org/release/Blender4.5/`.
The executable is a local development tool and is not part of this asset pack.

From the project root:

```powershell
& 'D:\DevCache\helios-blender\blender-4.5.9-windows-x64\blender.exe' --background --python-exit-code 1 --python tools/build_helix_miner.py -- --bake
python tests/miner_asset_contract_test.py
.\tools\run_miner_preview.ps1
```

`-Capture` on the preview launcher runs the focused 4K rendering regression and
writes evidence under the ignored `artifacts/ui/miner/` directory. Preview mode
does not read/write player saves. The separate Hurricane reference scene remains
available through `tools/run_art_calibration.ps1`.

## Current limits

One authored camera direction, prototype material wear and one lighting setup.
The soft shadow and accent mask are static passes; they do not capture every
moving-part shadow. These are independent images sampled with per-frame mipmaps,
not a shipping texture-array/atlas streaming system. No multiple-building load
benchmark, LOD mesh set or production Factory building replacement is claimed.
